Project overview

Northline is a fictional creative studio, used as the basis for exploring an intentional, modular visual identity. The project includes a wordmark, color system, typography hierarchy, and a small set of repeatable graphic elements.

The challenge

A useful visual identity needs to work consistently across formats. The goal was to create a system that felt editorial and contemporary without relying on a large number of ornamental elements.

Design approach

I paired a bold dark-green foundation with sage, warm clay, and neutral chalk. The geometric N symbol provides an anchor for compact applications, while typography and circles form a simple recognizable visual vocabulary.

What the concept includes

  • Primary wordmark and compact lettermark
  • Four-color palette with hexadecimal values
  • Typography treatment and recurring geometric elements
