# Josie Madrigal — design concept portfolio website

Open `index.html` in a browser. The site works offline except for optional Google Fonts, which fall back to system fonts.

This static site has four separate case studies with original, high-resolution vector SVG illustrations. All case studies are clearly disclosed as independent illustrative concepts, not verified professional design commissions. The resume confirms engineering history but not proficiency in every listed creative application.

## Structure
- `index.html`: portfolio home, filters, about, creative disciplines, contact
- `projects/`: four complete case-study pages
- `assets/`: SVG illustrations and stylesheet

You can publish the full directory to GitHub Pages, Netlify, or Vercel.
